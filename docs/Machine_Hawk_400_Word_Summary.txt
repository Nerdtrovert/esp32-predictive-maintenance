Machine Hawk is an edge AI predictive maintenance platform that integrates embedded systems, machine learning, MQTT communication, backend analytics and a professional web dashboard to monitor industrial equipment. The solution is built around an ESP32 microcontroller with an MPU6050 vibration sensor and a DHT22 temperature sensor. Vibration data is collected and used to train an Edge Impulse machine learning model, which is exported as an Arduino library and deployed directly on the ESP32 for real-time anomaly detection.

The device continuously analyses vibration patterns locally, enabling rapid detection of abnormal machine behaviour without relying entirely on cloud processing. Temperature readings are analysed separately to provide trend prediction and support maintenance decisions. Using MQTT, the ESP32 publishes sensor readings and anomaly information to a Python backend which processes incoming data computes health scores and generates maintenance recommendations.

A React-based web application presents the information through an enterprise-style dashboard. Rather than displaying only raw telemetry, the dashboard focuses on actionable insights such as overall health score, failure risk, active alerts, AI recommendations, maintenance schedules and equipment status. This allows maintenance engineers and plant managers to quickly understand machine conditions and make informed decisions.

Machine Hawk follows a complete end-to-end architecture that integrates sensing, edge intelligence, communication, analytics and visualisation. The project demonstrates practical use of embedded AI, Industrial IoT communication and modern web technologies in a single platform. By performing inference directly on the edge device, the system reduces latency, lowers bandwidth usage and improves reliability for industrial monitoring.

The platform can be extended with cloud deployment, multiple machine support, predictive remaining useful life estimation, OTA firmware updates and mobile applications. Machine Hawk demonstrates how affordable hardware and edge intelligence can deliver an effective predictive maintenance solution for manufacturing environments and small to medium industries while showcasing the integration of embedded systems, artificial intelligence, networking and full-stack software development.
